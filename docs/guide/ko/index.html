HTML 과 CSS 로 쓴 Dioxus,Compose 가 네이티브로 그립니다.

웹에서 쓰듯 앱을 씁니다. div, h1, flexbox, 스타일시트, 훅과 시그널입니다. dioxus-compose 가 Rust 에서 배치하고, 그 결과를 compose-rust 를 거쳐 Compose Multiplatform 이 그리도록 넘깁니다.

배포하는 프로그램에 웹뷰도 JVM 도 없습니다. rsx! 안에서 Compose 위젯 이름도 씁니다.

시작하기 가이드 보기 GitHub
  • 웹뷰 없음
  • 배포 바이너리에 JVM 없음
  • 쓰던 CSS 를 Rust 에서 배치
  • 한글 포함 플랫폼 IME 그대로
rsx! {
    main { class: "page",
        h1 { "Hello, Dioxus" }
        p {
            a {
                href: "#",
                onclick: move |event| {
                    event.prevent_default();
                    hellos += 1;
                },
                "Say hello"
            }
        }
    }
}

CSS 는 Rust 에서, 픽셀은 Compose 에서

blitz-dom 이 Rust 프로세스 안에서 스타일시트를 풀고 페이지를 배치합니다. Dioxus 자체의 네이티브 렌더러가 쓰는 엔진과 같습니다. Compose 가 받는 것은 CSS 가 아니라 사각형, 색, 텍스트 조각이고, Compose 는 자기 텍스트 스택과 입력기로 그것을 그립니다.

지금 HTML 경로는 화면을 배치하고 그리기를 계획하며, 그것을 그리는 다리는 만들고 있습니다 (현황). 위젯 경로는 지금 그려집니다.
