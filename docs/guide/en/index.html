Dioxus in HTML and CSS,drawn natively by Compose.

Write your app the way you would for the web: div, h1, flexbox, a stylesheet, hooks and signals. dioxus-compose lays it out in Rust and hands the result to Compose Multiplatform, through compose-rust, to draw.

No webview and no JVM in what you ship. Compose widget names work in rsx! too.

Get started Read the guide GitHub
  • No webview
  • No JVM in the shipped binary
  • Your CSS, laid out in Rust
  • Platform IME, including Korean
rsx! {
    main { class: "page",
        h1 { "Hello, Dioxus" }
        p {
            a {
                href: "#",
                onclick: move |event| {
                    event.prevent_default();
                    hellos += 1;
                },
                "Say hello"
            }
        }
    }
}

CSS in Rust, pixels in Compose

blitz-dom resolves your stylesheet and lays the page out inside the Rust process, the same engines Dioxus's own native renderer uses. Compose receives rectangles, colours and runs of text, never CSS, and draws them with its own text stack and input method.

Today the HTML path lays screens out and plans the drawing, and the bridge that draws them is being built (status). The widget path draws now.
